# NYXR website

The official NYXR product website. Built with React and Vite; deployed as static pages.

Use Node 24, `npm ci`, `npm run dev`.

Read [DEPLOYMENT.md](DEPLOYMENT.md) before connecting Vercel or publishing beta downloads.
The desktop app is not included in this repository. Your own provider keys or a local model power NYXR.

The public beta link is guarded until reviewed installer and matching source assets are available.
No installer or credentials are committed here.
