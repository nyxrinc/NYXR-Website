# NYXR website

The official NYXR product website. Built with React and Vite; deployed as static pages.

Use Node 24, `npm ci`, `npm run dev`.

Read [DEPLOYMENT.md](DEPLOYMENT.md) before connecting Vercel or publishing beta downloads.
The desktop app is not included in this repository. Your own provider keys or a local model power NYXR.

The public beta link is guarded until reviewed installer and matching source assets are available.
No installer or credentials are committed here.

## Public beta

- Website: https://nyxr-website.vercel.app
- Download: https://nyxr-website.vercel.app/download/
- Release, source, checksums and acceptance scope: https://github.com/nyxrinc/NYXR-Website/releases/tag/v4.0.0-beta.3

The Windows x64 beta is unsigned. Hosted NYXR accounts and the Chrome Store
listing are not configured; manual extension setup is documented. Clean-laptop
and physical voice testing remain outstanding. This is separate from a signed
stable release. The release record contains exact public asset hashes and sizes.

## NEXUS update

The current screenshots show the actual beta3 interface: onyx surfaces, a cursor-responsive NYXR core, Electrolize Regular headings, Chakra Petch interface text and JetBrains Mono code. The tutorial is optional and covers provider setup plus separate listening/speaking checks.
